カクヨム中継サーバーの作り方

EbookForge Web はブラウザの中だけで動くため、ブラウザの制限でカクヨムのページを直接読めません。あなた専用の小さな中継サーバー（Cloudflare Workers・無料枠）を1つ作ると、作品URLを貼るだけで取り込めるようになります。iPhoneのSafariだけで作れます（10分ほど）。

1. 合言葉を作る

中継サーバーを他人に使われないための合言葉です。下のボタンで作り、メモアプリ等に控えてください。

2. Cloudflare に登録する

  1. Cloudflare の登録ページでメールアドレスとパスワードを入れて登録し、届いた確認メールのリンクを開きます（無料）。

3. Worker（中継サーバー）を作る

  1. Cloudflare の画面で「Workers & Pages」→「作成（Create）」→「Worker を作成（Create Worker）」を選びます。
  2. 名前を入れて（例：ef-kakuyomu）「デプロイ（Deploy）」を押します。
  3. 「コードを編集（Edit code）」を開き、最初から入っているコードを全部消して、下の「中継サーバーのコード」を貼り付け、「デプロイ（Deploy）」を押します。

コードは worker/kakuyomu-relay.js と同じものです。カクヨムの作品ページと話のページ以外は取りに行かず、取得した本文を保存しません。

4. 合言葉を登録する

  1. 作った Worker の「設定（Settings）」→「変数とシークレット（Variables and Secrets）」→「追加（Add）」を押します。
  2. 種類（Type）は「シークレット（Secret）」、名前（Variable name）は KEY、値（Value）に 1. で作った合言葉を貼り、「デプロイ（Deploy）」を押します。

EbookForge Web を https://boufuuuuuu.github.io 以外の場所で使う場合だけ、もう1つ変数 ALLOW_ORIGIN（値：そのページの https://〜 の部分）を追加してください。

5. アプリに設定する

  1. Worker の画面に表示されるURL（https://ef-kakuyomu.〇〇.workers.dev）をコピーします。
  2. EbookForge Web の「③ 本を読み込む」→「カクヨムの作品URLから取り込む」を開き、「中継サーバーのURL」にそのURL、「合言葉」に 1. の合言葉を入れます。
  3. カクヨムの作品URLを貼って「取り込む」を押します。1話あたり約1.5秒かかります（カクヨムに負荷をかけないため）。

うまくいかないとき

  • 「合言葉が違います」：4. の名前が KEY になっているか、値に余分な空白が入っていないか確認してください。
  • 「中継サーバーに接続できませんでした」：URLが https:// で始まっているか、3. でデプロイしたかを確認してください。
  • 「目次を読み取れませんでした」「本文の場所を見つけられませんでした」：カクヨムのページの作りが変わった可能性があります。表示された文をそのまま開発者に知らせてください。

Cloudflare の画面の文言は変わることがあります。本文は私的利用の範囲で使い、他人に渡さないでください。小説家になろうは利用規約で自動取得が禁止されているため対象外です。
